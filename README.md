# 本地密码管理器

一个运行在 Windows 本地的轻量级密码管理工具。

密码库由用户自行保存，软件不依赖服务器即可运行。适合记录日常注册的网站、应用账号以及对应密码，方便以后查询和管理。

## 当前版本

**v1.2.1**

## 功能

### 密码库

- 首次使用时创建密码库
- 可自行选择密码库保存位置
- 支持打开已有密码库
- 支持迁移密码库到新的位置
- 密码库文件由用户自行管理
- 配置文件记录当前密码库位置

### 密码管理

- 添加密码记录
- 修改密码记录
- 删除密码记录
- 查看密码详情
- 搜索网站名称 / 应用名称
- 搜索用户名
- 按网站名称 / 应用名称排序
- 显示 / 隐藏密码
- 复制用户名
- 复制密码
- 打开网站地址

每条密码记录包含：

- 网站名称 / 应用名称
- 网址
- 用户名
- 密码
- 备注

### 主密码

- 使用主密码保护密码库
- 支持修改主密码
- 支持锁定当前密码库
- 主密码不会保存到配置文件中

### 安全

密码库采用本地加密方式保存敏感数据。

当前使用：

- **Argon2id**：用于主密码验证及密钥派生
- **AES-256-GCM**：用于密码和备注等敏感数据的加密
- 随机 Salt
- 随机 Nonce
- 独立的加密密钥派生

软件运行过程中，加密密钥仅用于当前运行会话，锁定密码库后会清除当前会话中的加密密钥。

> 本项目为个人本地密码管理工具，并不是经过专业安全审计的商业密码管理产品。请根据自己的安全需求决定是否使用。

### 更新检查

- 程序启动时自动检查最新版本
- 关于窗口支持手动检查更新
- 发现新版本时提示用户
- 可以打开 GitHub 发布页面获取新版本
- 更新检查失败不会影响程序正常使用

[下载 PasswordManager v1.2.1](https://github.com/WenZoo1982/PasswordManager/releases/tag/v1.2.1)
