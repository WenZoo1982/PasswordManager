# 本地密码管理器

一个运行在 Windows 本地的轻量级密码管理工具。

密码库由用户自行保存，软件不依赖服务器即可运行。适合记录日常注册的网站、应用账号以及对应密码，方便以后查询和管理。

## 当前版本

**v1.1.0**

## 功能

### 密码库

- 首次使用时创建密码库
- 可自行选择密码库保存位置
- 支持打开已有密码库
- 支持迁移密码库到新的位置
- 密码库文件由用户自行管理
- 配置文件记录当前密码库位置

### 密码管理

- 添加密码记录
- 修改密码记录
- 删除密码记录
- 查看密码详情
- 搜索网站名称 / 应用名称
- 搜索用户名
- 按网站名称 / 应用名称排序
- 显示 / 隐藏密码
- 复制用户名
- 复制密码
- 打开网站地址

每条密码记录包含：

- 网站名称 / 应用名称
- 网址
- 用户名
- 密码
- 备注

### 主密码

- 使用主密码保护密码库
- 支持修改主密码
- 支持锁定当前密码库
- 主密码不会保存到配置文件中

### 安全

密码库采用本地加密方式保存敏感数据。

当前使用：

- **Argon2id**：用于主密码验证及密钥派生
- **AES-256-GCM**：用于密码和备注等敏感数据的加密
- 随机 Salt
- 随机 Nonce
- 独立的加密密钥派生

软件运行过程中，加密密钥仅用于当前运行会话，锁定密码库后会清除当前会话中的加密密钥。

> 本项目为个人本地密码管理工具，并不是经过专业安全审计的商业密码管理产品。请根据自己的安全需求决定是否使用。

## 使用方式

### 1. 下载

从 GitHub Releases 下载对应版本。

发布版本采用 Windows x64 自包含方式，不要求另外安装 .NET Runtime。

### 2. 第一次运行

第一次运行程序时：

1. 选择密码库保存位置
2. 创建主密码
3. 完成密码库初始化

密码库文件的位置由用户自行选择。

### 3. 以后运行

程序会读取程序目录下的：

```text
config.json
```

找到之前设置的密码库后，显示主密码解锁界面。

如果 `config.json` 不存在，或者原密码库已经不存在，可以重新选择已有密码库。

### 4. 密码库迁移

如果需要将密码库移动到另一块硬盘或其他目录，可以使用：

**迁移密码库**

程序会复制完整的密码库文件，并在验证成功后更新配置。

原密码库文件不会自动删除。

## 文件说明

程序目录中的主要文件：

```text
PasswordManager.exe
config.json
```

密码库文件：

```text
*.dat
```

其中：

- `PasswordManager.exe`：程序
- `config.json`：记录当前密码库位置
- `*.dat`：实际密码库文件

### 请妥善保存

以下内容都非常重要：

- 密码库文件
- `config.json`
- 主密码

其中任何一项出现丢失、损坏或主密码遗忘，都可能导致无法正常访问密码数据。

特别是：

**软件不会保存你的主密码，也没有服务器端密码恢复功能。**
